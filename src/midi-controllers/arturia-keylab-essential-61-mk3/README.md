# Arturia KeyLab Essential 61 mk3

This knowledge base tracks the Arturia KeyLab Essential 61 mk3 as a 61-key
MIDI keyboard, DAW controller, and direct controller for the Roland XPS-30.
It does not generate audio: route its MIDI to a software instrument or
hardware sound module, then route that sound source separately.

## Documented Hardware Summary

- 61 velocity-sensitive, synth-action keys.
- Eight velocity- and aftertouch-sensitive performance pads.
- Nine endless encoders, nine faders, pitch and modulation wheels, display,
  and DAW command controls.
- USB-C power and MIDI, a five-pin MIDI output, and a 1/4-inch TRS control
  pedal input for sustain, switch, or expression control.
- Arturia, DAW, and User programs; up to six User programs can be saved from
  MIDI Control Center.
- No internal sound engine or audio output.
