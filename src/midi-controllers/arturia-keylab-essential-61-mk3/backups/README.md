Before changing firmware, a User program, a MIDI Control Center setting, or a
large mapping group, export what the editor supports and make a visual record
of the controller state.

Evidence can include MIDI Control Center exports, photographs, DAW templates,
and matching entries in \`mappings/README.md\`. Do not label a backup as trusted
until a mapping has been restored or rebuilt from it.
