# KeyLab Essential 61 mk3 Manuals

This directory retains the official documentation needed to reproduce the
controller setup. The official source is listed in [manuals.md](manuals.md).

- \`source/\` holds original documents when a local copy has been retained.
- \`extracted/\` holds text extracted from those originals for repository search.
- \`manuals.json\` records source URLs, local filenames, and integrity data.

The original official manual is retained locally and extracted for repository
search. Its version, checksum, and source URL are recorded in \`manuals.json\`.
