# KeyLab Essential 61 mk3 Mapping Log

Use this directory for observed configuration, not intended configuration.
Record the KeyLab program, USB endpoint, channel, and destination for every
mapping that needs to be recreated without relying on MIDI Control Center.

| Date | Program | Control / Range | MIDI Type | Value / Note / CC | Channel | Input Endpoint | Output Endpoint | Destination | Status | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |  |  |  |  |

For direct XPS-30 control, record the five-pin cable, KeyLab transmit channel,
XPS-30 receive part, and selected patch or performance. For DAW control,
record the DAW version, program, protocol, input and output endpoints, and
whether MIDI feedback is working. Add a backup entry whenever a mapping changes.
