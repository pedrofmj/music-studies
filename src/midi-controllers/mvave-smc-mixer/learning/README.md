# SMC-Mixer Learning Path

## Session 1: USB Surface Baseline

1. Record battery behavior, physical fader positions, current mode, and host
   MIDI endpoint.
2. Connect with USB-C and confirm both input and output endpoints.
3. Create eight disposable DAW tracks and verify fader movement.
4. Test one encoder and each track-button function on one track.
5. Record the DAW name, endpoint names, and mode in [Mappings](../mappings/README.md).

## Session 2: Mackie Control

1. Configure the documented Mackie Control recipe for one DAW.
2. Verify play, stop, record, select, mute, solo, and bank movement.
3. Move a fader when the pickup LED indicates disagreement; observe the point
   at which the DAW value begins to follow it.
4. Save a screenshot or notes of the DAW control-surface configuration.

## Session 3: User Mode

1. Switch to User mode with Shift plus the documented channel control.
2. Map only four controls: one fader, one encoder, play, and stop.
3. Verify that the custom mapping does not affect the Mackie Control setup.
4. Save the resulting editor or DAW mapping evidence in [Backups](../backups/README.md).

Keep DAW and User-mode assignments separate. The fastest way to create a
confusing control surface is to let multiple mappings claim the same control.
