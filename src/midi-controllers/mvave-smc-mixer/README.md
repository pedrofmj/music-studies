# M-VAVE SMC-Mixer

This knowledge base covers the SMC-Mixer wireless DAW control surface. Despite
its name, it is not an audio mixer: it sends MIDI and Mackie Control commands
to a host DAW.

## Start Here

1. [Learning](learning/README.md) - establish USB control before BLE or DAW
   presets.
2. [Reference](reference/README.md) - Mackie Control recipes and operational
   behavior.
3. [Manual Guide](manual/manuals.md) - stored official PDF and integrity data.

## Verified Hardware Summary

- 8 touch-sensitive faders.
- 8 rotary encoders.
- 43 programmable LED buttons.
- USB-C and BLE MIDI control paths.
- 780mAh battery; 256 x 122 x 40 mm; 445 g.
