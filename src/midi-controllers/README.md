# MIDI Controllers

This collection contains controller-specific knowledge bases and a shared
workflow for M-VAVE devices used with the Roland XPS-30, Linux, mobile music
software, and DAWs. The SMK25 and SMC devices send MIDI or DAW-control data;
the FM-1 is also a self-contained FM synthesizer with audio output.

## Shared Guidance

- [M-VAVE Shared Workflows](mvave-workflows.md) - USB, BLE MIDI, Linux,
  multi-device routing, and safe configuration habits.
- Every device keeps learning and reference material, a downloaded official
  manual, mapping records, and a backup log.

## Study Rule

Establish and document a reliable USB connection before configuring BLE MIDI,
DAW presets, custom mappings, SysEx imports, or firmware. Record the actual
Linux port name, MIDI channel, preset, and destination in the relevant
mappings directory.
