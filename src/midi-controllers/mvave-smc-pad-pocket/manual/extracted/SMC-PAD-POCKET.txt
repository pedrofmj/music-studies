Pad Modes:
Switch between Note mode (default) and Control mode. In Control mode, pads
function as assignable buttons rather than note triggers.


  PAD1

  Mode     Pad              Type     Note         Channel      Channel 10

  Note     36       C (2)          Minvel   0        Maxvel     127

  Led      255        Color




Control Types:
•Note: Send standard MIDI note messages
•CC Toggle: Toggle between two CC values with each press
•Momentary: Send one CC value on press, another on release
•Program Change: Send MIDI program change messages
•Custom: Input and send System Exclusive (SysEx) messages


•Channel: Assign MIDI channels to individual pads note :
•Note: Customize the MIDI note for each pad
•MinVel: Set the minimum velocity threshold for pad triggering
•MaxVel: Set the maximum velocity limit for pad triggering
•Color: Assign custom colors to pads for visual organization

四.软件参数介绍                                                          CN
打击垫模式：
在音符模式（默认）和控制模式之间切换。在控制模式下，触控板
功能为可分配的按钮，而不是音符触发器（Note)。

 PAD1

 Mode   Pad           Type     Note       Channel    Channel 10

 Note   36    C (2)          Minvel   0     Maxvel    127

 Led    255    Color



控制类型：
•音符(Note)：发送标准MIDI音符码
•CC切换（CC Toggle)：每次按下在两个CC值之间切换
•瞬时(Momentary)：按下时发送一个CC值，释放时发送另一个
•程序变更(Program Change)：发送MIDI程序变更消息
•自定义：输入并发送系统（System exclusive）消息

•通道（Channel）：为各个打击垫分配MIDI通道
•音符（Note）：自定义每个打击垫的MIDI音符
•最小力度（MinVel）：设置触控板触发的最小力度阈值
•最大力度（MaxVel）：设置触控板触发的最大力度限制
•颜色（Color）：为触控板分配自定义颜色
