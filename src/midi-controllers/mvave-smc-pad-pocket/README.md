# M-VAVE SMC-PAD Pocket

This knowledge base covers the SMC-PAD Pocket ultra-portable wireless pad
controller. It is distinct from the larger SMC-PAD: it has no encoders or
transport surface but provides seven pad banks and mobile-oriented preset work.

## Start Here

1. [Learning](learning/README.md) - connection, preset, and pad-bank sessions.

3. [Manual Guide](manual/manuals.md) - stored official PDF and integrity data.

## Verified Hardware Summary

- 16 RGB velocity-sensitive, aftertouch-capable pads.
- 7 pad banks x 16 pads, for 112 note positions.
- USB-C MIDI and BLE MIDI.
- 780mAh battery; 105 x 105 x 16 mm; 130 g.
- Note repeat, rate, swing, latch, and bank controls assignable in the vendor
  software.
