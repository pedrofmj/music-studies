# SMC-PAD Pocket Learning Path

## Session 1: USB And Preset Baseline

1. Record battery state, current pad colors, and startup preset.
2. Connect over USB-C and record the host MIDI endpoint.
3. Test all 16 pads in the selected bank, including velocity and aftertouch.
4. Photograph the visible layout and enter notes, channels, colors, and targets
   in [Mappings](../mappings/README.md).

## Session 2: Factory Presets

1. Boot each of presets 1-4 using the documented power-on gesture.
2. Test each only in its intended host context: Ableton Drum Rack, FL Studio
   FPC, GarageBand drums, or control pads.
3. Record the actual MIDI output rather than trusting the preset name.
4. Choose one baseline preset for the primary workflow and back it up.

## Session 3: Seven-Bank Layout

1. Reserve Bank 1 for dependable drums or sample triggers.
2. Reserve one bank for transitions or control buttons.
3. Put experiments in a separate bank and document them fully.
4. Test note repeat with local tempo and external sync before using it live.
5. Verify that a wireless MIDI adapter, if used, does not take over the host
   connection unexpectedly.

A pocket controller becomes useful through stable bank discipline. Use the 112
possible notes deliberately rather than filling banks without a retrieval plan.
