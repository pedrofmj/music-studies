# Controller Backup Log

Before changing a vendor editor, firmware, preset, or large mapping group, save
what can be exported and also make a visual record of the controller state.

| Date | Device State | Editor/App Version | Firmware | Backup or Evidence Location | Restore Test | Notes |
| --- | --- | --- | --- | --- | --- | --- |
|  |  |  |  |  |  |  |

Evidence can include editor exports, screenshots, photographs, DAW templates,
and the corresponding entry in `mappings/README.md`. Do not label a backup as
trusted until a mapping can be rebuilt or restored from it.
