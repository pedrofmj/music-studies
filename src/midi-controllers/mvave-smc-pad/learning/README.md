# SMC-PAD Learning Path

## Session 1: Safe Baseline

1. Record preset, battery state, pad colors, USB endpoint, and any existing
   custom configuration.
2. Connect through USB-C and test every pad for note output.
3. Test pad velocity, aftertouch, one encoder, and both bank buttons.
4. Record pad number, output, channel, and destination in [Mappings](../mappings/README.md).

## Session 2: Presets And Transport

1. Identify the performance and DAW presets before changing them.
2. Configure one DAW as Mackie Control and verify Play, Stop, Record, Left, and
   Right.
3. Test the second pad and encoder banks without overwriting the first bank.
4. Save evidence of the original and changed states in [Backups](../backups/README.md).

## Session 3: Note Repeat And MIDI Out

1. Test note repeat with a local tempo, then with DAW sync.
2. Record rate, swing, tempo, and latch decisions for one pad mapping.
3. Test 3.5 mm MIDI out only with a known target and documented adapter.
4. Create one stage-safe bank and leave experimental mappings outside it.

The aim is a rebuildable pad layout, not a large unexplained collection of
lights and notes.
