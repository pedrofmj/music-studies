# M-VAVE SMC-PAD

This knowledge base covers the full SMC-PAD controller: 16 expressive pads,
encoders, transport, two controller banks, and a 3.5 mm MIDI out port.

## Verified Hardware Summary

- 16 RGB velocity-sensitive, aftertouch-capable pads.
- 8 endless encoders and second pad/encoder banks.
- USB-C MIDI, BLE MIDI, and 3.5 mm wired MIDI out.
- Transport and DAW navigation controls.
- 2000mAh battery; 227 x 147 x 38 mm; 520 g.
