# M-VAVE SMK25

This knowledge base covers the original M-VAVE SMK25 25-key wireless MIDI
keyboard controller, not the later SMK25-II. The physical controller is useful
for compact keyboard practice, software instruments, pad triggering, DAW
transport, and controlled hardware-synth workflows.

## Verified Hardware Summary

- 25 full-size velocity-sensitive keys.
- 8 RGB pads with velocity and aftertouch, plus a second pad bank.
- 8 endless encoders, plus a second encoder bank.
- Pitch and modulation touch strips.
- USB-B MIDI, BLE MIDI, and a 1/4 inch port used for sustain by default.
- 2000mAh battery; 321 x 178 x 46 mm; 750 g.
