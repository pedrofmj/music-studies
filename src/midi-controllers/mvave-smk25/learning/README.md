# SMK25 Learning Path

Use the reference only when you need an answer; this file is the ordered
keyboard work.

## Session 1: Baseline And USB

1. Record the device color, serial label, firmware state if visible, battery
   behavior, and current preset.
2. Connect by USB-B and list the host MIDI endpoint.
3. Test keys across the range, pitch strip, modulation strip, one pad, and one
   encoder.
4. Write the exact result in [Mappings](../mappings/README.md).
5. Photograph the default control layout before editing it.

Done when a USB MIDI endpoint and a plain note path are repeatable.

## Session 2: Performance Controls

1. Test octave shift and transpose reset.
2. Select both pad and encoder banks and document all 16 physical positions.
3. Test a single DAW transport preset with Play, Stop, and Record.
4. Create one conservative mapping: keys for a piano, pads for noncritical
   samples or clips, and one encoder for an audible software parameter.
5. Save or photograph the state and log it in [Backups](../backups/README.md).

## Session 3: Musical Functions

1. Compare arpeggiator timing with local tempo and DAW sync.
2. Practice one Smart Scale and one Smart Chord setting, recording the key,
   scale, chord type, and exit method.
3. Decide whether those functions belong in the live setup or only in practice.
4. Document the chosen operating preset and destination.

Do not make the pedal port a MIDI output until sustain behavior has been
accounted for in the intended setup.
