# PipeWire Manual Inventory

The [PipeWire project page](https://pipewire.org/) and
[PipeWire documentation](https://docs.pipewire.org/) are the current official
documentation sources. The project page is recorded in manuals.json as web
documentation only.

No PDF or text extraction is retained in this repository yet. If an authorized
official PDF is added later, retain it in source/, create the matching
pdftotext -layout output in extracted/, and update the source manifest with its
revision, size, page count, SHA-256, and retrieval date.
