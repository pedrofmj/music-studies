# Documented Capabilities

Source: [PipeWire project page](https://pipewire.org/).

The project describes PipeWire as a Linux audio and video project with a
low-latency graph-based processing engine. The official page lists these
relevant capabilities:

- audio capture and playback with minimal latency;
- real-time audio processing;
- multiprocess multimedia sharing;
- compatibility paths for PulseAudio, JACK, ALSA, and GStreamer applications;
- support for sandboxed applications.

These are project capabilities, not proof of a local route, low latency target,
or client result. Record actual observations in the Linux baseline and
checklists.
