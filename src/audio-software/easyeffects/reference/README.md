# EasyEffects Reference And Test Records

This directory separates project documentation from Linux observations. It does
not define a Windows equivalent.

- [Documented capabilities](01-documented-capabilities.md) records official
  effect and PipeWire statements.
- [Safety and device baseline](02-safety-and-device-baseline.md) records the
  device-routing rule and minimum evidence.
- [Output chain checklist](03-output-chain-checklist.md) records speaker or
  headphone processing.
- [Input chain checklist](04-input-chain-checklist.md) records microphone or
  line-input processing.

Use the official [EasyEffects project repository](https://github.com/wwmm/easyeffects)
and [help pages](https://wwmm.github.io/easyeffects/) for documented behavior.
Local records must include OS, EasyEffects version, PipeWire version, device,
effect chain, preset, steps, and result.
