# Documented Capabilities

Source: [EasyEffects project repository](https://github.com/wwmm/easyeffects).

EasyEffects is documented as a collection of effects for PipeWire applications.
The official project lists processing such as equalization, compression,
limiting, convolution, filtering, gates, noise reduction, pitch shifting,
reverberation, and level measurement.

The project also documents distribution packages and Flatpak as installation
paths. Availability of a specific effect can depend on installed plugin
dependencies. This record does not claim that every listed effect is present on
the local Linux installation.
