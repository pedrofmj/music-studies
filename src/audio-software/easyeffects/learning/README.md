# EasyEffects Learning Path

These sessions apply to Linux only. Complete the PipeWire baseline before
testing EasyEffects. Record EasyEffects version, PipeWire version, selected
device, enabled effects, preset name, and result in reference/ after each test.

## 01. Establish A Device Baseline

Open EasyEffects with no effects enabled. Identify the intended output device
and, when needed, input device. Confirm ordinary playback and capture behavior
before adding effects.

Success condition: the intended hardware remains available and the baseline
record identifies each selected device.

## 02. Build A Minimal Output Chain

Enable one output effect only, such as an equalizer or limiter, and make one
small intentional adjustment. Compare monitored playback with the effect
enabled and disabled.

Success condition: the effect change is observable, the chosen output remains
stable, and the exact effect settings are recorded.

## 03. Build A Minimal Input Chain

Only when microphone or line input processing is needed, enable one input
effect and perform a short capture or monitoring test. Keep input and output
chain results separate.

Success condition: the intended input remains selected, the effect change is
observable, and the test does not alter the documented output chain.

## 04. Save And Recover

Save the tested configuration or preset using the application workflow. Restart
the application, check the selected device, and repeat one short playback or
capture test.

Success condition: the required chain can be restored from the recorded preset
and settings without relying on memory.
