# Documented Capabilities

Source: [Equalizer APO about page](https://equalizer-apo.org/about/).

The project describes Equalizer APO as an open-source audio equalizer for
Windows. Its official description states that it can use an unlimited number of
filters across any number of audio channels and that changes update
immediately.

These project statements do not prove that a selected Windows device, driver,
application, or filter setting works locally. Record those outcomes in the
device and application checklists.
