# Equalizer APO Reference And Test Records

This directory separates official project claims from Windows observations. It
does not define a Linux equivalent.

- [Documented capabilities](01-documented-capabilities.md) records the official
  Windows equalizer statements.
- [Windows device baseline](02-windows-device-baseline.md) establishes the
  selected playback evidence.
- [Filter checklist](03-filter-checklist.md) records reversible filters.
- [Application compatibility checklist](04-application-compatibility-checklist.md)
  records the tested application and playback result.

Use the official [Equalizer APO project](https://equalizer-apo.org/) and
[about page](https://equalizer-apo.org/about/) for documented behavior. Local
records must include Windows version, Equalizer APO version, device, driver,
filter configuration, test application, steps, and result.
