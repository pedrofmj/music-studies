# Carla Projects

This directory contains versioned Carla project files and the metadata needed
to deploy them. Large sample libraries, SoundFonts, plugin binaries, and
machine-local PipeWire state remain external.

## Projects

- [Pedro Live Rack](pedro-live-rack/README.md) is the active multi-controller
  performance rack deployed as `/c/music/carla/pedro.uproject` on `airstar`.
