# Carla Reference And Test Records

This directory separates project documentation from actual machine evidence.
Do not promote a local success to a general Linux or Windows compatibility
claim.

- [Documented capabilities](01-documented-capabilities.md) records the official
  host, format, and driver claims relevant to this study.
- [Platform baseline](02-platform-baseline.md) defines minimum evidence for each OS.
- [Device integration checklist](03-device-integration-checklist.md) records
  controller, audio interface, and patchbay tests.

Use the [KXStudio Carla page](https://kx.studio/Applications:Carla) as the
official source. Local test notes must state Carla version, OS, driver,
interface or device, endpoint, plugin format, steps, and result.
