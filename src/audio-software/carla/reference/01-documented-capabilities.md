# Documented Capabilities

Source: [KXStudio Carla application page](https://kx.studio/Applications:Carla).
This record reports documented project capabilities, not plugins or routes that
have been verified on a local computer.

## Host And Routing Roles

- Carla is a modular audio plugin host with transport control, MIDI CC
  automation, and OSC remote control.
- It provides rack and patchbay processing modes.
- JACK is described as the default and preferred audio driver.
- The project also lists native driver paths including ALSA and DirectSound.
