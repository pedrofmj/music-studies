## Source Notes

- Roland lists one wave expansion slot for the XPS-30 and says the slot is
  rewritable through USB flash drive workflow.
- Roland's XPS-30 support page lists JUNO-DS Tone Manager and Librarian
  downloads for Windows and macOS, with notes that JUNO-DS drivers can also be
  used for the XPS-30.
- Roland's Axial category page explicitly groups `JUNO-DS61 / 76 / 88 / XPS-30`
  together for the compatible expansion list.
- Roland's DP-10 page describes the pedal as full and half-damper compatible.
