# Samples

Use this area to plan sample-pad content and track what is loaded on USB media.

## Official Format Facts To Verify In Practice

Roland's product page lists:

- Sample import audio format: WAV, 44.1 kHz, 16-bit.
- Audio file player formats: WAV, AIFF, MP3.
- Eight phrase pads for triggering samples or audio songs from USB memory.

## Worship Sample Categories

- Drone.
- Choir.
- Rise.
- Impact.
- Reverse cymbal.
- Ambient FX.
- Intro.
- Transition FX.

## Naming

Use predictable filenames:

```text
category_key_duration_bpm_optional.wav
```

Examples:

```text
drone_d_90s.wav
rise_soft_08s.wav
impact_low_03s.wav
```
