# XPS-30 Reference

[Structured capabilities](capabilities.json) records source-linked ports, signal directions, connection constraints, and supported roles.

This is the lookup and procedure side of the project. It contains explanations,
answers, setup recipes, catalog conventions, and operational guidance. It is
not a study checklist; the ordered keyboard work lives in
[Learning](../learning/README.md).

## Contents

1. [Fundamentals](01-fundamentals.md) - architecture, terminology, limits, and
   signal flow.
2. [Worship Live Setup](02-worship-live-setup.md) - favorite-bank layout,
   baseline performance recipes, stage rules, and pedal guidance.
3. [Linux Workflow](03-linux-workflow.md) - Ubuntu-first procedures for USB
   media, downloads, archives, checksums, backups, and samples.
4. [Axial Expansions](04-axial-expansions.md) - official compatibility list,
   worship priorities, and expansion rotation procedure.
5. [Sound Catalog](05-sound-catalog.md) - patch rating and tagging definitions.

Official sources and manual links are collected in
[Official Resources](../references/official-resources.md).
