## Worship Priority Hypothesis

Start with these. Confirm by listening and cataloging, not by name alone.

| Priority | Expansion | Reason to test |
| --- | --- | --- |
| 1 | `EXP-09 Complete Piano Collection` | Broad piano coverage for worship foundation |
| 2 | `EXP-04 Concert Piano Collection` | Focused acoustic piano option |
| 3 | `EXP-05 Electric Piano Collection` | Rhodes-style and vintage EP worship sounds |
| 4 | `EXP-08 Strings Collection` | Pad-like string support and chorus lift |
| 5 | `EXP-10 Orchestra Collection` | Strings, brass, and orchestral layers |
| 6 | `XV-5080 Collection Preset Bank E` | Piano, organ, EP, strings, brass, and choir emphasis |
| 7 | `EXP-06 Studio Collection` | General pop/rock toolkit; Roland says it is preloaded out of the box |

## Rotation Strategy

The XPS-30 has one wave expansion slot, so every expansion test should follow
the same procedure:

1. Back up the current state.
2. Record the currently loaded expansion.
3. Install one candidate expansion.
4. Audition and catalog useful patches.
5. Build one or two test performances.
6. Decide whether the expansion stays loaded.
7. Back up again after useful work is saved.
