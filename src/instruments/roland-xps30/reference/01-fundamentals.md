# Fundamentals

Use XPS-30 terminology consistently. In casual discussion, "tone" often means
"sound", but this study should prefer the names used by the instrument and
manuals: patch, drum kit, performance, part, favorite, phrase pad, sample, and
wave expansion.

## Mental Model

The practical live-performance model is:

```text
waveforms / samples
  -> patch or drum kit
  -> performance part
  -> performance layers / splits
  -> effects
  -> output
```

For study purposes:

- A patch is the basic playable sound.
- A drum kit is a percussion-oriented playable sound.
- A performance is a multi-part setup for layers, splits, MIDI use, and live
  combinations.
- A part is one slot inside a performance.
- A favorite is a stage-navigation shortcut.
- A phrase pad triggers assigned sample/audio material.
- A wave expansion replaces or fills the internal expansion slot with additional
  source waveforms and patches.

## Core Limits To Respect

- Maximum polyphony is 128 voices.
- A performance can use 16 parts.
- User memory includes 128 performances and 100 favorites.
- There is one rewritable wave expansion slot.

These limits should shape the live setup. Worship layers can become dense very
quickly, especially with stereo patches, sustain pedal use, pads with long
release, strings, and layered pianos.

## Practical Consequences

- Begin with a patch when one sound is enough. Use a performance when you need
  layers, splits, multiple MIDI parts, or a saved combination.
- Build the dry sound relationship before using reverb and chorus. Effects can
  make an imbalanced layer appear acceptable at home but fail in a mix.
- Treat favorites as pointers to proven sounds and performances, not as the
  sound design itself.
- Leave headroom in dense piano, pad, and strings layers. Long releases and
  sustain consume polyphony and can blur the accompaniment.
- Keep the DP-10 assigned to its intended hold/sustain behavior before adding
  other controllers.
