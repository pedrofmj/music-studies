# Sound Catalog Reference

Use these conventions whenever recording factory sounds, expansion sounds,
favorite candidates, performances, or phrase-pad material. The active survey
procedure is in [Learning: Sound Survey](../learning/02-sound-survey.md).

## Record Format

| Source | Number | Name | Category | Tags | Rating | Worship Use | Notes |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Factory |  |  | Piano | `piano`, `default` |  | Main worship piano |  |
| Factory |  |  | Pad | `pad`, `warm` |  | Under piano |  |
| Expansion |  |  | Strings | `strings`, `lift` |  | Big chorus |  |

## Rating Meaning

- `5` - stage-ready and dependable without further work.
- `4` - useful after minor level, EQ, or effect adjustment.
- `3` - useful only for a specific context.
- `2` - retained for study or a possible future use.
- `1` - not useful for this worship setup.

## Tags

Core sound-family tags:

- `piano`, `ep`, `pad`, `strings`, `choir`, `organ`, `lead`, `brass`, `fx`

Arrangement and behavior tags:

- `split`, `layer`, `soft`, `bright`, `dark`, `wide`, `mono-safe`

Worship-function tags:

- `prayer`, `chorus`, `intro`, `transition`

## Rating Guidance

Rate a sound for its actual role, rather than its appeal in isolation. A pad
that sounds impressive alone can be a poor worship layer if it masks vocals or
the piano attack. Conversely, a restrained pad that leaves space for the band
is often a stronger stage choice. Record the monitoring context in `Notes` so
the rating remains meaningful later.
