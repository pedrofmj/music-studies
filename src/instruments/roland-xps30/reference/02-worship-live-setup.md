# Worship Live Setup

The live setup should make common service decisions fast: piano now, pad under
vocal prayer, bigger chorus, soft transition, organ support, and emergency
fallbacks.

## Favorite Bank Plan

The XPS-30 has 100 favorites, so use ten banks of ten.

| Bank | Theme | Purpose |
| --- | --- | --- |
| 0 | Core Pianos | Reliable acoustic piano choices |
| 1 | Piano + Pad | Main worship layers |
| 2 | Soft Prayer | Quiet piano, pad, choir, and felt-style sounds |
| 3 | Electric Pianos | Rhodes, Wurli-style, bell EP, soft EP layers |
| 4 | Pads | Warm, bright, motion, shimmer-like, and drone pads |
| 5 | Strings / Choir | Support layers, intros, and big endings |
| 6 | Organs | Worship organ support and swells |
| 7 | Leads / Brass | Synth leads, brass stabs, melody support |
| 8 | FX / Samples | Risers, impacts, reverse cymbal, ambient FX |
| 9 | Service Set | Weekly song-specific favorites |

## Baseline Performances

| Name | Layers | Use |
| --- | --- | --- |
| Main Worship Piano | Concert-style piano + warm pad | Default congregational playing |
| Soft Prayer | Soft piano + ambient pad | Prayer, ministry, quiet transitions |
| Rhodes Worship | Electric piano + soft strings | Mid-tempo verses and reflective songs |
| Big Chorus | Piano + wide pad + strings | Full-band chorus lift |
| Pad Bed | Low-motion pad | Spoken prayer, scripture reading, transitions |
| Organ Support | Organ + optional pad | Gospel, hymn, or energetic sections |

## Stage Rules

- Keep one unlayered piano favorite available at all times.
- Keep one soft pad-only favorite available at all times.
- Put service-specific experiments in Bank 9 until proven.
- Balance sounds at rehearsal volume, not bedroom volume.
- Check Auto Off behavior before live use.
- Back up before replacing an expansion or rewriting many favorites.
