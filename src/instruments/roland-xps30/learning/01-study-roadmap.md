# Roadmap

This roadmap turns the XPS-30 into a long-term study project instead of a loose
collection of notes.

For the concrete first actions, start with [Start Here](00-start-here.md). This
roadmap describes the longer phases after the initial baseline and backup are in
place.

## Phase 0 - Baseline

Objectives:

- Record the current system version.
- Back up the current keyboard state before changing anything.
- Photograph or write down the current pedal, audio, MIDI, and USB setup.
- Create an initial favorite-bank plan without overwriting useful existing data.

Evidence to store:

- System version.
- Backup filename and date.
- USB drive label and format.
- Current expansion slot content.
- Current favorite banks.

## Phase 1 - Instrument Fundamentals

Learn the XPS-30 vocabulary and signal flow:

- Patch, drum kit, performance, part, favorite, phrase pad, sample, expansion.
- How patch mode differs from performance mode.
- How a performance combines parts, levels, splits, layers, and effects.
- Where polyphony can be consumed quickly.
- How controllers affect live expression.

Exercises:

- Select ten factory patches and write one sentence about each sound.
- Build a two-layer piano/pad performance.
- Build a left-hand pad and right-hand piano split.
- Save nothing until the same setup can be rebuilt from notes.

## Phase 2 - Factory Sound Survey

Create a sound catalog before chasing expansions.

For each useful sound, capture:

- Patch number and name.
- Category.
- Best worship use.
- Weaknesses.
- Favorite-bank destination.
- Whether it works alone, layered, or split.

Prioritize:

- Acoustic pianos.
- Electric pianos.
- Warm pads.
- Strings.
- Organs.
- Choirs.
- Soft synth leads.
- Ambient FX.

## Phase 3 - Favorites

Design the 100 favorites as stage navigation, not as a random bookmark list.

Target result:

- Ten banks of ten sounds.
- Consistent placement across banks.
- Emergency fallbacks for piano, pad, and piano plus pad.
- Service-specific slots that can change weekly.

## Phase 4 - Worship Performances

Build a small set of reliable performances:

- Main Worship Piano.
- Soft Prayer.
- Rhodes Worship.
- Big Chorus.
- Organ Support.
- Pad Bed.
- Strings Lift.
- Service Intro.

Each performance should document:

- Parts used.
- Split points.
- Layer balance.
- MFX, chorus, and reverb intent.
- Pedal assignments.
- Known songs or service moments.

## Phase 5 - Linux Workflow

Prove the Ubuntu workflow before depending on it live:

- Prepare a keyboard-formatted USB drive.
- Store downloaded expansion archives outside the keyboard backup directory.
- Unzip archives and inspect included readme files.
- Record checksums for downloaded files.
- Copy only the files required by the keyboard procedure.
- Keep a dated backup before any system update or expansion change.

## Phase 6 - Axial Expansions

Evaluate expansions one at a time because the XPS-30 has one wave expansion
slot.

Initial worship-oriented candidates:

- `EXP-04 Concert Piano Collection`
- `EXP-05 Electric Piano Collection`
- `EXP-08 Strings Collection`
- `EXP-09 Complete Piano Collection`
- `EXP-10 Orchestra Collection`
- `XV-5080 Collection Preset Bank E`

## Phase 7 - Advanced Sound Design

Move from preset use to intentional editing:

- Filter cutoff and resonance.
- Envelopes.
- LFO.
- Velocity response.
- Layer balance.
- Effects routing.
- Controller assignments.

Rule: document every edit well enough that it can be rebuilt.
