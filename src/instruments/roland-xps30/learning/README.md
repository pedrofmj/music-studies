# XPS-30 Learning Path

This is the active study path. It tells you what to do at the keyboard, what to
record, and what a completed session should produce. It deliberately avoids
giving the technical answer in the exercise itself; use the linked reference
material when you need an explanation or a repeatable setup procedure.

## Follow This Order

1. [Start Here](00-start-here.md) - establish a safe baseline and finish the
   first three sessions.
2. [Study Roadmap](01-study-roadmap.md) - work through the longer phases.
3. [Sound Survey](02-sound-survey.md) - evaluate factory and expansion sounds
   consistently.
4. [Practice Log](03-practice-log.md) - retain the results of every session.

## Use The Reference Material When

- A term such as patch, performance, part, favorite, phrase pad, or expansion
  is unclear: [Fundamentals](../reference/01-fundamentals.md).
- You need a worship bank layout or a dependable performance recipe:
  [Worship Live Setup](../reference/02-worship-live-setup.md).
- You are preparing USB media, archives, backups, samples, or updates:
  [Linux Workflow](../reference/03-linux-workflow.md).
- You are deciding whether an Axial expansion is worth the only wave-expansion
  slot: [Axial Expansions](../reference/04-axial-expansions.md).
- You need the rating scale or tags while cataloging a sound:
  [Sound Catalog](../reference/05-sound-catalog.md).
- You want to understand the history, timbre, and musical role of a sound
  family: [Keyboard Sound Exploration](../../../music-theory/learning/03-keyboard-sound-exploration.md)
  and [What A Keyboard Really Is](../../../music-theory/reference/01-what-a-keyboard-really-is.md).
