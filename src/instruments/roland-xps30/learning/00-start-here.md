# Start Here

Follow this sequence before branching into the rest of the material. The goal is
to build a safe baseline first, then learn the instrument through small usable
setups.

## Sequence Overview

| Step | Work | Main File | Done When |
| --- | --- | --- | --- |
| 1 | Identify current keyboard state | This file | System version, expansion, and current favorites are recorded |
| 2 | Make a first backup | [Backups](../backups/README.md) | A dated backup exists before edits |
| 3 | Learn the core vocabulary | [Fundamentals](../reference/01-fundamentals.md) | Patch, performance, part, favorite, and phrase pad are clear |
| 4 | Test factory sounds | [Sound Survey](02-sound-survey.md) | At least 10 useful sounds are cataloged |
| 5 | Build one simple live performance | [Performances](../performances/README.md) | Piano plus pad can be rebuilt from notes |
| 6 | Create the first favorite bank | [Favorites](../favorites/README.md) | Bank 0 has dependable piano choices |
| 7 | Prepare the Linux workflow | [Linux Workflow](../reference/03-linux-workflow.md) | USB, downloads, checksums, and backups have a repeatable process |
| 8 | Evaluate expansions | [Axial Expansions](../reference/04-axial-expansions.md) | One expansion is tested at a time with before/after backups |
| 9 | Expand the worship setup | [Worship Live Setup](../reference/02-worship-live-setup.md) | Core service sounds are organized for fast navigation |
| 10 | Begin deeper editing | [Study Roadmap](01-study-roadmap.md) | You can explain and rebuild your sounds, not only recall them |

## First Session

Do this before changing anything on the XPS-30:

1. Open the keyboard system information screen and record the installed system
   version.
2. Record which wave expansion is currently loaded.
3. Write down whether any favorites or user performances already matter.
4. Connect the DP-10 and confirm that hold/sustain behaves correctly.
5. Create the first backup and log it in [Backups](../backups/README.md).

Use this entry:

```text
Date:
System version:
Current expansion:
Important existing favorites:
Important existing performances:
Backup filename:
USB drive label:
Notes:
```

Do not edit favorites, performances, samples, or expansions until this baseline
exists.

## Second Session

Read [Fundamentals](../reference/01-fundamentals.md), then do only these
hands-on tasks:

1. Select five acoustic piano patches.
2. Select five pad or string patches.
3. Catalog them in [Sound Survey](02-sound-survey.md).
4. Choose one piano and one pad for a first layer.
5. Document the exact patch names and levels in
   [Performances](../performances/README.md).

The target is not a perfect sound. The target is a documented sound that can be
rebuilt.

## Third Session

Create a first worship-ready navigation setup:

1. Put the best unlayered piano in favorite `0-0`.
2. Add up to four more piano choices in Bank 0.
3. Put the first piano-plus-pad performance in Bank 1.
4. Keep Bank 9 empty for weekly service experiments.
5. Back up after the favorite changes.
