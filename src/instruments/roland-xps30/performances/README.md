## Starter Performances

### Main Worship Piano

Purpose:

- Default full-band congregational sound.

Layers:

- Acoustic piano.
- Warm pad.

To define:

- Exact patch names.
- Part levels.
- Reverb amount.
- Whether the pad responds to sustain.

### Soft Prayer

Purpose:

- Quiet prayer, ministry, scripture, and transitions.

Layers:

- Soft piano.
- Ambient pad.

### Rhodes Worship

Purpose:

- Reflective verses, mid-tempo songs, and softer arrangements.

Layers:

- Electric piano.
- Optional soft strings or pad.

### Big Chorus

Purpose:

- High-energy chorus lift.

Layers:

- Piano.
- Wide pad.
- Strings.
