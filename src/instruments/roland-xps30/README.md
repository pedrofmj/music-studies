# Roland XPS-30

This directory is the working knowledge base for mastering the Roland XPS-30 as
a live worship keyboard and long-term synthesis study instrument. It separates
active keyboard work from stable answers and procedures.

## Start Here

Choose the branch that matches the task:

1. [Learning](learning/README.md) - the ordered sessions, exercises, survey,
   roadmap, and practice log.
2. [Reference](reference/README.md) - concepts, answers, recipes, tips, and
   operational procedures without exercises.

Start with [Learning: Start Here](learning/00-start-here.md). Consult the
reference material as needed; do not begin expansion work until the first
backup and factory-sound survey exist.

## Goals

- Master the XPS-30 architecture, front-panel workflow, menus, and terminology.
- Build a reproducible worship setup for piano, pads, strings, organs, leads,
  samples, and service-specific performances.
- Keep favorites, performances, samples, expansions, and backups documented.
- Prefer Ubuntu/Linux workflows for downloads, USB preparation, backups, sample
  organization, and versioned notes.
- Use official Roland resources first, then clearly mark any experiments or
  community-derived ideas.

## Verified Starting Facts

As of 2026-07-16, Roland official XPS-30 pages describe the instrument with
these high-level facts:

- 61 velocity-sensitive keys.
- 128-voice maximum polyphony.
- 16 parts.
- Preset memory: more than 1400 patches, more than 35 drum kits, and 28
  performances.
- User memory: 256 patches, 8 drum kits, 128 performances, and 100 favorites.
- One rewritable wave expansion slot.
- Sample import supports WAV files at 44.1 kHz, 16-bit; system version 2.00 or
  later adds multi-sample support with JUNO-DS Tone Manager.
- Eight phrase pads can trigger samples or audio files from USB memory.
- USB computer connection supports USB MIDI and audio.
- The latest official system program found during setup is `Ver.2.12`, released
  March 2025.

Source links are tracked in [official resources](references/official-resources.md).
