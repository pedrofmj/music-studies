# XPS-30 Manuals

This directory contains the official XPS-30 PDF set, a Markdown guide, a JSON
manifest, and personal study notes.

## Manual Indexes

- [Manual Guide](manuals.md) - reading order, document roles, local PDF links,
  and official sources.
- [Manual Manifest](manuals.json) - machine-readable paths, sources, page
  counts, file sizes, and SHA-256 digests.
- [PDF Source Cache](source/README.md) - internal-study provenance for the
  stored original PDFs.

## Storage Scope

The PDFs in `source/` are stored for internal study. Keep the original files
paired with their official Roland source URLs and do not redistribute them
outside the authorized internal scope.

## Personal Notes

Add concise notes derived from reading the manuals here or in the relevant
reference file. Preserve the source page and manual section for each note;
write explanations and procedures in your own words rather than reproducing
manual text.
