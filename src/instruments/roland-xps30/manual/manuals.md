## Recommended Reading Order

1. Read the Owner&#39;s Manual first to establish the front-panel and mode model.
2. Read the Version 2 Supplementary Manual next if the keyboard is on Version 2
   or later.
3. Use the Parameter Guide as a lookup reference while editing sounds,
   performances, effects, and controllers.
4. Read MIDI Implementation only when configuring a computer, DAW, external
   controller, or SysEx workflow.
5. Treat the Version 1.04 Supplementary Manual as historical context after
   confirming that a Version 2 manual does not supersede the topic.
6. Use the Tone Manager guide only for the supported desktop workflow; it is not
   a Linux-first tool.

## Integrity

`manuals.json` records the exact local filename, byte size, page count, direct
Roland download URL, and SHA-256 digest for every stored PDF. Recalculate the
digest after a future re-download before replacing an existing local file.
