# Instruments

Instrument studies live here. Each instrument should have its own directory with
documentation, setup notes, references, and inventories.

## Current Studies

- [Roland XPS-30](roland-xps30/README.md) - expandable synthesizer study plan,
  worship setup, Linux workflow, sound catalog, and live performance notes.

## Naming

Use lowercase, hyphen-separated directory names:

- `roland-xps30`
- `yamaha-montage-m`
- `nord-stage-4`

Keep the manufacturer's exact product spelling in document titles.
