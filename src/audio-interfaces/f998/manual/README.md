# Manual Inventory

The retained manual is a one-page F998 podcast-bundle sheet. It provides the
device class, intended use, and headline controls, but not a complete, revision
specific port or signal specification. The manufacturer identification and a
two-page filed user manual are available through the FCC record, but direct
attachment retrieval was blocked by its host.

Use [manuals.json](manuals.json) for source authority, checksums, and the
retrieval status. The physical unit labels take precedence over generic F998
retail documentation.
