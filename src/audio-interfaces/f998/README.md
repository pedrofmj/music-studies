# F998 Live Sound Card Study And Integration

F998 is a portable live-streaming sound card and small audio mixer/effects
board. It is designed for microphone processing, backing-track playback,
headphone monitoring, phone/live-stream outputs, Bluetooth accompaniment, and a
computer/OTG audio path. It is not a MIDI controller or a replacement for the
TEYUN A8 as a line-level keyboard submixer.

## Identity Status

The FCC filing for product code `F998` identifies **Shenzhen Furuijie Electronic
Technology Co., Ltd.** as the applicant/manufacturer. F998 is also sold under
many retail brands, including FACMOGU, so the retail brand of this unit remains
unknown until its label is photographed. See [Source Assessment](references/sources.md).
