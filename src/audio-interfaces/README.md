# Audio Interfaces And Mixers

This collection documents devices that route, mix, monitor, record, or play
audio. Unlike MIDI controllers, these devices carry audio signals and do not
create or translate MIDI unless their documentation explicitly says so.

## Devices

- [TEYUN A8](teyun-a8/README.md) - compact analog mixer with provisional USB
  audio-interface documentation and XPS-30/FM-1 routing recipes.
- [F998 Live Sound Card](f998/README.md) - FCC-identified portable streaming
  sound card with retail revision and port labels pending physical confirmation.
